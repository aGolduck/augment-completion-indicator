# Augment 完成监控 - 测试流程文档

## 🛠️ 准备工作

### 1. 启用详细日志

打开 VSCode 设置（`Ctrl+,`），添加：

```json
{
  "augmentCompletionIndicator.verbose": true,
  "augmentCompletionIndicator.enabled": true
}
```

### 2. 打开输出面板

- 按 `Ctrl+Shift+U` 打开输出面板
- 在下拉菜单中选择 "Augment Completion Indicator"

### 3. 调整测试参数（可选）

为了加快测试速度，可以缩短倒计时：

```json
{
  "augmentCompletionIndicator.idleThreshold": 20,
  "augmentCompletionIndicator.warmupPeriod": 5
}
```

---

## 📋 测试用例

### 测试 1：预热期保护

**目的**：验证启动后预热期内忽略所有活动

**步骤**：
1. 重新加载窗口（`Ctrl+Shift+P` → `Reload Window`）
2. **立即**（5秒内）在终端执行：`echo "warmup test"`

**预期结果**：
```
[时间] ℹ️ ⏳ 预热期内，忽略命令结束: echo "warmup test"
```

**验证点**：
- ✅ 活动被忽略
- ✅ `activityCount` 保持为 0
- ✅ 不进入活跃状态

---

### 测试 2：窗口焦点过滤

**目的**：验证窗口有焦点时忽略活动

**步骤**：
1. 等待预热期结束（5秒后）
2. **保持 VSCode 窗口有焦点**
3. 在终端执行：`echo "focus test"`

**预期结果**：
```
[时间] ℹ️ 👁️ 窗口有焦点，忽略命令结束: echo "focus test"
```

**验证点**：
- ✅ 活动被忽略
- ✅ `activityCount` 保持为 0
- ✅ 不进入活跃状态

---

### 测试 3：命令结束检测（核心功能）

**目的**：验证窗口无焦点时命令结束被正确记录

**步骤**：
1. 等待预热期结束
2. 在 VSCode 终端输入：`sleep 5 && echo "test"`
3. **立即切换到其他窗口**（浏览器、文件管理器等）
4. 保持在其他窗口，等待 5 秒
5. 观察输出面板

**预期结果**：
```
[时间] ℹ️ 🔍 窗口焦点状态变化: 有焦点 → 无焦点
[时间] ℹ️ ✅ 命令结束 [成功] #1: sleep 5 && echo "test"
[时间] ℹ️ ✅ 进入活跃状态
[时间] ℹ️ ⏱️ 开始 20 秒空闲倒计时
```

**验证点**：
- ✅ 命令结束被检测到
- ✅ `activityCount = 1`
- ✅ 进入活跃状态
- ✅ 开始倒计时

3. 切换回 VSCode，再执行命令：`echo "second"`
4. 立即切换到其他窗口
5. 观察输出面板

**预期结果**：
```
[时间] ℹ️ ✅ 命令结束 [成功] #1: sleep 5 && echo "test"
[时间] ℹ️ ⏱️ 开始 20 秒空闲倒计时
... 10秒后 ...
[时间] ℹ️ ✅ 命令结束 [成功] #2: echo "second"
[时间] ℹ️ ⏱️ 开始 20 秒空闲倒计时  ← 重新开始
```

**验证点**：
- ✅ `activityCount = 2`
- ✅ 倒计时重新开始
- ✅ 需要再等 20 秒才会标记

## 🐛 常见问题排查

### 问题 1：命令结束没有被检测到

**可能原因**：
1. 窗口有焦点
2. 在预热期内
3. Shell Integration 未启用

**排查步骤**：
1. 检查输出面板是否有 "窗口有焦点，忽略" 日志
2. 检查是否在启动后 10 秒内
3. 检查终端是否支持 Shell Integration

### 问题 2：标记没有显示

**可能原因**：
1. 倒计时未完成
2. 窗口获得了焦点
3. 没有进入活跃状态

**排查步骤**：
1. 执行 `Augment: 显示监控状态` 查看当前状态
2. 检查 `距上次活动` 是否超过阈值
3. 检查输出面板是否有完成消息

### 问题 3：verbose 日志太多

**解决方案**：
```json
{
  "augmentCompletionIndicator.verbose": false
}
```
