## 📊 核心概念速查

### 三种状态

| 状态 | 说明 | 触发条件 |
|------|------|---------|
| 空闲 | 无活动 | 插件启动 / 窗口获得焦点 |
| 活跃 | 检测到活动 | 命令结束 / 文档变化 / 网络请求（窗口无焦点） |
| 已标记 | 任务完成 | 活跃状态 + 60秒无新活动 |

### 关键过滤

所有活动检测都必须通过：
1. ✅ 预热期过滤（启动后 10 秒）
2. ✅ 窗口焦点过滤（有焦点时忽略）
3. ✅ 白名单过滤（文档 scheme）
4. ✅ API 过滤（Augment API）

### 默认配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `idleThreshold` | 60秒 | 空闲倒计时时长 |
| `warmupPeriod` | 10秒 | 启动预热期 |
| `completionMarker` | `🔔 ` | 完成标记符号 |
| `enabled` | `true` | 是否启用监控 |
| `verbose` | `false` | 详细日志模式 |
